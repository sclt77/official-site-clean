# ClayBBS 官方服务中心

ClayBBS 官方服务中心用于管理 ClayBBS 与 CUTOT 产品的授权、版本发布、更新包、下载记录和站点服务。它面向软件提供方和站点运营方，帮助完成软件授权校验、版本分发、升级包管理和服务记录查询。

## 主要功能

- 授权码管理：创建、启用、禁用和查询授权。
- 站点绑定：记录授权对应的域名、站点信息和使用状态。
- 版本管理：发布完整安装包、增量更新包和回滚包。
- 更新服务：为已授权站点提供检查更新、下载更新和更新结果上报。
- 产品区分：分别管理 ClayBBS 与 CUTOT，避免不同产品的授权和更新包混用。
- 后台管理：管理员可在后台维护授权、版本、下载和相关服务数据。

## 运行环境

建议环境：

- Linux 服务器
- Nginx 或 Apache
- PHP 8.1 或更高版本
- MySQL 5.7 / 8.0 或兼容数据库
- PDO MySQL 扩展
- OpenSSL 扩展
- Zip 扩展
- Curl 扩展

## 安装步骤

### 1. 上传程序

将程序文件上传到你的网站目录，并将站点运行目录指向程序根目录。

### 2. 配置伪静态

Nginx 推荐配置：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

Apache 请确保已启用 `mod_rewrite`。

### 3. 配置数据库

创建一个 MySQL 数据库，并准备好：

- 数据库地址
- 数据库名称
- 数据库用户名
- 数据库密码

### 4. 访问安装向导

在浏览器中打开你的域名，按页面提示完成：

1. 环境检测
2. 数据库配置
3. 管理员账号创建
4. 初始化完成

### 5. 登录后台

安装完成后，使用管理员账号登录后台，进入授权、版本和更新包管理页面。

## 版本发布说明

发布新版本时，建议按以下流程操作：

1. 准备完整安装包。
2. 在后台选择对应产品：ClayBBS 或 CUTOT。
3. 上传完整包并填写版本号、更新说明和发布状态。
4. 系统会根据产品类型生成对应更新包。
5. 已授权站点可在自己的后台检查并下载更新。

## 更新包注意事项

- ClayBBS 与 CUTOT 是两个不同产品，更新包不能混用。
- 上传版本时请确认产品类型正确。
- 发布前建议先在测试站点验证安装和升级流程。
- 更新包应保留用户上传文件、配置文件和运行数据。

## 日常维护

建议定期：

- 备份数据库。
- 备份上传的安装包和更新包。
- 检查授权异常记录。
- 检查服务器磁盘空间。
- 更新 PHP 和数据库安全补丁。

## 常见问题

### 授权校验失败怎么办？

请检查授权码、绑定域名、服务器时间和网络连接是否正常。

### 更新包下载失败怎么办？

请检查站点授权状态、版本是否可升级、服务器是否能访问官方服务中心。

### 上传包后没有生成预期更新包怎么办？

请确认上传时选择了正确产品，并检查完整包结构是否正确。

## 安全建议

- 不要将数据库密码、后台账号或私钥公开。
- 后台入口建议限制管理员访问。
- 定期更换管理员密码。
- 生产环境请开启 HTTPS。
